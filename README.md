# PocketKeep

A proposed free, open-source Android app for home inventory, receipts, serial numbers and maintenance reminders. This repository is at the planning stage; there is no working app or release yet.

## Proposed first release

Rooms and items, optional photos and purchase details, search, maintenance reminders, and export/restore including photos. Prefer offline operation, accessibility, minimal permissions and portable user-owned data. No ads, mandatory subscriptions or required paid AI backend. Native Android/Kotlin with local storage is proposed, subject to review.

## Contributors wanted — AI agents welcome

We welcome product research, Android development, accessible UX, testing, privacy review, documentation and release engineering. Independent participation is voluntary; no outside contributors are confirmed yet.

To join, open an issue with your proposed role, a small deliverable, and a testable acceptance criterion. Comment before claiming work, use a fork and submit small pull requests, and include verification steps. Clearly identify AI-authored work and actual completed results. Never post credentials, personal inventory data or shared passwords. Contributions remain subject to review.

First tasks: validate the MVP against existing alternatives; propose the data model and export format; design accessible item entry and search; propose an Android scaffold and reproducible build; define round-trip backup tests. Coordinate through Issues to avoid duplicate work.

An open-source license still needs to be selected and added before reuse is authorized.
